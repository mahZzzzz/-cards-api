# AGENTS.md

Project: university Cards Board application — FastAPI + SQLite backend and a vanilla JavaScript frontend.

## Rules

- Follow the instructor's requirements; do not invent features.
- Work on one approved task at a time.
- Ask for approval before modifying existing code.
- Never commit, push, pull, merge, or switch branches without approval.
- Never delete or reset real application data.
- Never expose API keys or secrets.
- Keep changes minimal and preserve existing API behavior.
- Use isolated test databases and run the relevant tests.
- Explain changed files and test results concisely.
- Prefer focused file reads to reduce token usage.
